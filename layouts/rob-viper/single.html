Designed for honest visibility

Less mystery.
More evidence.

Review a code identity, a policy revision, and a recorded result together. Collection state, permissions, queue losses, response errors, and configuration drafts have separate indicators.

Private by default

Local, bounded event logs, optional connection history and private scan reports. Scanners read files only within a selected scope; they do not upload contents or reports. Official database downloads contact their publishers. Event logging excludes command arguments and environment values; network filtering excludes payloads.

Explicit scope

Execution rules use kernel signing metadata: exact CDHash overrides app identity, which overrides publisher. Lockdown denies unknown identities and deadline-pressure cases in Enforce; Audit always allows. macOS platform binaries and verified Viper recovery components remain protected. Publisher trust requires macOS 26 signing categories. Network hostname rules need macOS metadata; a shared IP or PTR name is not an exclusive website identity.

Complement existing defenses

The preview combines policy controls, local scanning and explainable investigation signals. It is not a certified antivirus product, a universal threat feed, a cleanup service or a replacement for Apple’s built-in protections. Allowed interpreters can still run scripts; this policy does not inspect script contents.

Release status / November 2026

Built to earn a place on your Mac.

Verified in development

Version 0.7 passes 181 Swift tests. New scanner regressions cover command injection, output floods, cancellation, stale databases, scope limits, rule mutation and behavior-analysis load. Real ClamAV, Trivy and YARA-X fixtures verify signatures, CVEs and pattern matches without executing malware. Earlier execution tests cover publisher impersonation, rule precedence, policy persistence and GUI/native agreement. All 37 scanner and behavior tests also pass Address Sanitizer. Earlier native bridge checks passed Address, Undefined Behavior and Thread Sanitizers. A 128-rule load test returns all 30,000 mocked authorization replies despite a stalled logger. Live Audit verified a production publisher, a more specific app override and an ad hoc impostor. No live executions were blocked. Earlier scoped network tests verified Audit, deny, answered approval and reverse DNS.

Required before public installation

Developer ID distribution approval, production signing, notarization, live managed-device delivery, execution blocking, broader VPN/multi-user network tests, and completed recovery exercises. Public downloads will appear here after those checks pass.

Publisher, signing-identity and lockdown rules share concepts with Santa’s application control. Viper does not implement Santa’s certificate or full-binary SHA-256 rules, compiler/transitive trust, or sync protocol. Monitor never blocks, Audit rehearses, and Enforce requires an explicit choice. This is not a claim of full Santa parity.

Scanner engines are installed separately. The tested baseline is ClamAV 1.5.4, Trivy 0.76.2 and YARA-X 1.23.0; keep them updated. Trivy checks supported dependency manifests, not every installed Mac app or macOS CVE. YARA needs operator-reviewed rules. Heuristics do not automatically block or quarantine, and incomplete scans remain visibly incomplete.

Traffic accounting uses macOS reports and can miss totals for short flows. This preview does not promise full feature parity with other firewalls, complete DNS association, malware cleanup or tamper resistance.

The full Endpoint Security agent will use a direct website/MDM installer. Apple does not accept Endpoint Security clients in the Mac App Store. An optional store companion is a future separate product, not a substitute for the agent.
