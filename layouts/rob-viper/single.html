Central administration.
Local decisions.

The management server owns enrollment, administrator accounts, groups, and profile delivery. ROB Viper applies supported execution rules locally. A network callback never waits for a web dashboard or an AI model.

Start with a pilot group in Audit. Verify outcomes, publish a higher policy revision, and then expand. Removing a managed profile restores local controls while retaining the last execution policy until it is changed.

Designed for honest visibility

Less mystery.
More evidence.

Review a code identity, a policy revision, and a recorded result together. Collection state, permissions, queue losses, response errors, and configuration drafts have separate indicators.

Private by default

Local, bounded event logs. No command arguments, environment values, file contents, or network payloads are collected by the current agent.

Explicit scope

CDHash rules target exact executable versions. Execution authorization allows under unknown identity or deadline pressure and reports that condition. An enforced outbound network allowlist blocks unlisted and unidentified destinations. Hostname rules need macOS metadata; an approved shared IP can represent several websites.

Complement existing defenses

This preview is a policy and visibility tool. It is not a certified antivirus product, a malware-reputation service, a recovery tool, or a replacement for Apple’s built-in protections.

Release status / November 2026

Built to earn a place on your Mac.

Verified in development

Version 0.4 passes 59 Swift tests. Its live allowlist Audit test completed 20 successful HTTPS requests, with 12 approved-destination matches and zero denied connections. Saved network rules survive reopening. Earlier live execution-monitoring tests include a 200-process fixture burst.

Required before public installation

Developer ID distribution approval, production signing, notarization, live managed-device delivery, execution and network enforcement tests, and completed recovery exercises. Public downloads will appear here after those checks pass.

The full Endpoint Security agent will use a direct website/MDM installer. Apple does not accept Endpoint Security clients in the Mac App Store. An optional store companion is a future separate product, not a substitute for the agent.
