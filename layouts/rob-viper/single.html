Designed for honest visibility

Less mystery.
More evidence.

Review a code identity, a policy revision, and a recorded result together. Collection state, permissions, queue losses, response errors, and configuration drafts have separate indicators.

Private by default

Local, bounded event logs. No command arguments, environment values, file contents, or network payloads are collected by the current agent.

Explicit scope

CDHash rules target exact executable versions. Network hostname rules depend on metadata supplied by macOS. Unknown identity and deadline pressure allow execution and are reported.

Complement existing defenses

This preview is a policy and visibility tool. It is not a certified antivirus product, a malware-reputation service, a recovery tool, or a replacement for Apple’s built-in protections.

45 Swift tests pass. The signed development app includes the execution service, policy studio, guided tour, and network filter target. Existing live execution-monitoring tests include a 200-process fixture burst.

Required before public installation

Developer ID distribution approval, production signing, notarization, live managed-device and network-filter tests, and a completed recovery exercise. Public downloads will appear here after those checks pass.

The full Endpoint Security agent will use a direct website/MDM installer. Apple does not accept Endpoint Security clients in the Mac App Store. An optional store companion is a future separate product, not a substitute for the agent.
