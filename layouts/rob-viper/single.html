Designed for honest visibility

Less mystery.
More evidence.

Review a code identity, a policy revision, and a recorded result together. Collection state, permissions, queue losses, response errors, and configuration drafts have separate indicators.

Private by default

Local, bounded event logs and optional private connection history. No command arguments, environment values, file contents or network payloads. Manual PTR queries use your configured resolver; subscribed list downloads contact the selected publisher.

Explicit scope

CDHash rules target exact executable versions. Execution authorization allows under unknown identity or deadline pressure and reports that condition. Network rules match verified publisher or exact-build identities, with separate actual-process controls. Identity deadline or overload denies in Enforce and allows in Audit. Hostname rules need macOS metadata; a shared IP or PTR name is not an exclusive website identity.

Complement existing defenses

This preview is a policy and visibility tool. It is not a certified antivirus product, a malware-reputation service, a recovery tool, or a replacement for Apple’s built-in protections.

Release status / November 2026

Built to earn a place on your Mac.

Verified in development

Version 0.5 passes 122 Swift tests, including a real executable claiming Safari’s identifier that fails trusted-publisher matching. Selected suites pass Address Sanitizer (52 tests) and Thread Sanitizer (9 tests). Scoped live tests verified Audit, a targeted deny, an answered approval, reverse DNS and filter shutdown. Unrelated control requests succeeded. Reproduction steps and exact evidence are maintained with the source.

Required before public installation

Developer ID distribution approval, production signing, notarization, live managed-device delivery, execution blocking, broader VPN/multi-user network tests, and completed recovery exercises. Public downloads will appear here after those checks pass.

Traffic accounting uses macOS reports and can miss totals for short flows. This preview does not promise full feature parity with other firewalls, complete DNS association, malware cleanup or tamper resistance.

The full Endpoint Security agent will use a direct website/MDM installer. Apple does not accept Endpoint Security clients in the Mac App Store. An optional store companion is a future separate product, not a substitute for the agent.
