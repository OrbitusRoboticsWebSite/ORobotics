New in 0.3 / Cloud Fleet

Receive ViperLink payloads from another network.

Queue an ordered command and file payload from ViperLink on Mac or iPhone, or from your administrator-provided fleet portal. The enrolled machine retrieves it through CloudKit and returns an encrypted execution receipt.

In RedAgent’s Cloud Fleet tab, choose your private receiver profile, set Check in every X minutes from 1 to 1,440, and enable cloud commands while the app is open. Apply interval changes, request an immediate check-in, or stop the receiver. The default interval is five minutes.

This optional feature requires Node.js 22 or later and individual enrollment. Public downloads contain no credentials. Commands run as the receiver’s user; failure stops later steps, and interrupted jobs are not automatically replayed. CloudKit indexing can delay a newly queued job until a later check-in.
