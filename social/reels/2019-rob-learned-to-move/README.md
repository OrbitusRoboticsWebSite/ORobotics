# 2019 — ROB learned to move

`rob-2019-recap.mp4` is a 9:16, silent, approximately 25-second reel assembled
from the public 2019 gallery videos. It moves from coordinated head/arm tests to
the planter-support experiment and closes on the 2026 Maker Faire target.

The reel is intentionally silent so a reviewer can choose cleared music inside
Facebook. Review every frame before upload, add the post copy and alt text from
`social/drafts/maker-faire-2026-ramp-up.md`, and confirm the event statement is
still accurate.

Rebuild from the repository root:

```sh
scripts/build-social-reel-2019.sh
```
